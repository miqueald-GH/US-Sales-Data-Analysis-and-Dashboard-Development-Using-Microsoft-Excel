# US-Sales-Data-Analysis-and-Dashboard-Development-Using-Microsoft-Excel
My Excel capstone project showcasing data cleaning, analysis, and visualization skills.

## Project Overview
This project involves analyzing US sales data using Microsoft Excel to explore sales performance, profitability, customer contributions and sales subcategories.

## Dataset Source
The dataset used for this project was obtained from kaggle.

## Tools Used
Microsoft Excel

## Key Analysis Areas
**Monthly Sales:** Analyzing sales performance across different months.

**Profit Overtime:** Examining changes in profit overtime.

**Top 5 Customers:** Identifying the top five customers by sales contribution.

**Sales by State:** Comparing sales performance across different states.

**Sales by Subcategory:** Exploring sales across products subcategories.

**Key Performance Indicators (KPIs):** Highlighting important sales and profitability metrics.
